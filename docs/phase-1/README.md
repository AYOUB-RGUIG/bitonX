# BitonX Phase 1

Phase 1 is limited to specification normalization and MVP freeze.

No application source code, framework scaffolding, migrations, services, AI modules, or deployment files are part of this phase.

## Source Specification

- Primary source: `docs/bitonX (1).pdf`
- Specification version: BitonX AI Engineering Specification Version 1.0
- Product name: BitonX Quant
- Current Phase 1 date: 2026-07-20

## Phase 1 Deliverables

This folder contains the Phase 1 control documents:

- `mvp-freeze.md`: locked MVP boundaries for the first buildable release.
- `architecture-baseline.md`: normalized architecture decisions to guide implementation.
- `requirements-backlog.md`: implementation backlog derived from the specification.
- `open-questions.md`: unresolved requirements that need product or engineering confirmation.

## Phase 1 Definition of Done

Phase 1 is complete when:

1. The MVP scope is explicit and implementation-ready.
2. Out-of-scope items are separated from the first build.
3. Architecture choices are normalized into a buildable baseline.
4. Ambiguous requirements are listed as open questions.
5. Later phases can proceed without reinterpreting the 127-page source specification.

## Implementation Gate

Implementation should not begin until these Phase 1 documents are accepted.
